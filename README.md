# DBARENA

Public, comparable benchmark results for hosted Postgres providers, published at [dbarena.com](https://dbarena.com).

## Repository layout

- `apps/web`: website (with `patches` and `brand` containing supporting assets)
- `results`: benchmark results, organized by provider
